# РОБОРАБ — сайт

Одностраничный сайт (ИИ для бизнеса) и демо-чат.

- `src/index.src.html`, `src/chat.src.html` — исходники страниц
- `assets/` — картинки и видео (встраиваются в страницу при сборке)
- `build.py` — сборка: `python3 build.py` → `dist/index.html`, `dist/chat.html`
- `dist/` — готовые файлы, можно открывать или выкладывать как есть

Форма на сайте отправляет имя и продукт в `chat.html` (`action="chat.html"` в блоке `#contact`).
Когда чат переедет на отдельный домен, нужно заменить этот адрес.

Ссылки на скачивание приложения (`#stores` в `index.src.html`) пока пустые.
